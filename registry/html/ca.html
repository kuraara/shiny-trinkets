Trust the home gadgets on this device

The gadgets use a secure (https) connection with a certificate made at home. Install it once on each phone or computer and the “not private” warnings go away. Phones can then also save clips straight to Photos.

Download the certificate

iPhone or iPad

  1. Open this page in Safari (Chrome can’t install it) and tap Download the certificate, then Allow.
  2. Open Settings: tap Profile Downloaded near the top, then Install (twice) and enter your passcode.
  3. Go to Settings → General → About → Certificate Trust Settings and turn on Home Gadgets local CA.
  4. Open the gadgets over https.

Mac

  1. Download the certificate and open it: it goes into Keychain Access.
  2. Double-click Home Gadgets local CA, open Trust, set When using this certificate to Always Trust.

Windows

  1. Download the certificate, open it and choose Install Certificate.
  2. Pick Local Machine, then Place all certificates in the following store → Trusted Root Certification Authorities.

Android

  1. Download the certificate, then Settings → Security → Encryption & credentials → Install a certificate → CA certificate.

The certificate can only vouch for addresses on the home network and local names (.local, .lan, .home.arpa), never for real websites, so installing it can’t be used to impersonate anything outside the house.
